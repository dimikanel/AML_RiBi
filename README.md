# AML_RiBi
Ribosome Biogenesis (RiBi) studies in Acute Myeloid Leukemia (AML)

For the development of a RiBi gene signature, we used RNA-Seq and demographic data from three previously characterized cohorts: a Swedish cohort called ClinSeq-AML(1)*, the BEAT-AML(2) and a Finnish cohort(3) that we named FINN-AML for this project. A total of 884 AML (inclusion criterion: primary disease, exclusion criteria: non-primary disease, acute promyelocytic leukemia samples) and 31 healthy samples (CD34+ bone marrow-derived blasts) were used in a differential expression (DE) analysis to find genes with altered expression in AML. DE genes were then subset based on a curated list of 379 RiBi regulators (GSEA GO:0042254, AmiGO GO:0042254 with the following filters: regulates_closure: GO:0042254, taxon subset closure label: Homo sapiens) and the remaining genes were used to build a LASSO-enriched COX regression model using the 884 AML samples. The analysis led to the identification of 31 genes that comprise the AML RiBi gene signature. The sum of the 31-gene expression multiplied by their weights gave the RiBi score for each sample. The regression model was validated in a separate cohort from the TCGA database (TCGA-AML) with 135 AML patient samples(4). ROC analysis was used to evaluate the performance of the model. Patients were grouped (RiBi status) in low (LR), moderate (MR), and high RiBi (HR) based on the distribution of their RiBi score (Q1:LR, Q2-Q3:MR, Q4:HR). The prognostic value of RiBi status on the survival of AML patients was calculated with the Kaplan-Meier method, whereas a multivariate hazard ratio analysis was used to determine the independent prognostic value of the RiBi status compared to known factors affecting prognosis (mutational status, age, sex, ELN2022). For the scRNA analysis, we used soupX-normalized scRNA data retrieved from Lasry and colleagues(5) and processed according to the original article. For the ENL2022 classification we used the system presented from Döhner and colleagues(6)
